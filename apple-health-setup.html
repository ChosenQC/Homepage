DAYBOOK / APPLE HEALTH

热量与睡眠，留在同一本日记里。

在 iPhone 上创建一个「Daybook 健康同步」快捷指令。只上传两类数据；没有记录的时段保留为空。

这是配置说明，需要在 iPhone 中创建一次快捷指令。网页不会直接读取你的苹果健康数据。不同 iOS 版本的动作名称可能略有差别。

1 · 准备连接码

  1. 用 iPhone Safari 打开你的完整 Book 同步链接，进入「健康 → 连接苹果健康」。
  2. 复制「上传地址」和「专属连接码」。连接码填入下面的 token，不要使用 Book 链接替代。
  3. 打开「快捷指令」，新建并命名为「Daybook 健康同步」。

2 · 活动热量

  1. 添加「查找健康样本」：类型选择活动能量／活动热量（Active Energy），开始日期为最近 3 天；关闭数量限制，不按天分组。把显示单位设为千卡（kcal），或保留千焦（kJ）。
  2. 在「来源」筛选中选择你的 Apple Watch。若更换过手表，先选目前这一块，避免手机和多个手表的重复记录。
  3. 添加「重复每一项」，输入为查找到的健康样本。
  4. 在重复内添加两次「格式化日期」：分别选重复项目的开始日期、结束日期，格式均选 ISO 8601。把两个输出分别重命名为「热量开始」「热量结束」。
  5. 在重复内添加「字典」，按下表设置。点击变量「重复项目」后可选择值、单位、来源等属性。字典须是重复内的最后一个动作。
字段类型与内容
start文本 →「热量开始」变量
end文本 →「热量结束」变量
value数字 → 重复项目的「值」
unit文本 → 重复项目的「单位」，例如 kcal 或 kJ
source文本 → 重复项目的「来源」
  1. 在「结束重复」后添加「合并文本」，输入选择这段循环的重复结果，分隔符设为自定：英文逗号 ,。把输出重命名为「热量 JSON」。字典会转换为 JSON 文本；没有样本时这里为空。

3 · 睡眠

  1. 再添加「查找健康样本」，类型选择睡眠（Sleep），开始日期为最近 3 天，来源选同一块手表，关闭数量限制。不要只查询“今天”，否则会漏掉午夜前开始的睡眠。
  2. 添加第二段「重复每一项」。同样将每项的开始、结束日期格式化为 ISO 8601，输出重命名为「睡眠开始」「睡眠结束」。
  3. 添加下面的字典，作为这段重复的最后一个动作。value 选择样本的“值”，不要选“类型”或“时长”；它应是核心睡眠、深睡、REM、清醒等阶段。
字段类型与内容
start文本 →「睡眠开始」变量
end文本 →「睡眠结束」变量
value文本 → 重复项目的「值」
source文本 → 重复项目的「来源」
  1. 在第二个「结束重复」之后添加「合并文本」，输入为第二段的重复结果，自定分隔符为英文逗号 ,。输出重命名为「睡眠 JSON」。

Daybook 会排除清醒和卧床时间，并合并重叠的睡眠段。没有戴表或没有读到睡眠时，不补算睡眠。无法识别的阶段会提示，不冒充有效睡眠。

4 · 上传

  1. 添加「文本」，复制下面模板。将连接码粘贴到引号内；将方括号中的两个占位文字分别替换成上面两个变量块，不要给变量再加引号。
{
  "token": "在这里粘贴连接码",
  "energy": [在这里插入「热量 JSON」变量],
  "sleep": [在这里插入「睡眠 JSON」变量]
}
  1. 添加「URL」，填入从 Daybook 复制的上传地址。
  2. 添加「获取 URL 内容」，方法设为 POST；请求头添加 Content-Type = application/json；请求体选择文件，插入上一步整理好的「文本」变量，让它作为整个 JSON 正文发送。
  3. 第一次测试可在末尾加「快速查看」，查看接口返回结果。ok: true 表示上传成功；received 是收到的样本数。0 条代表没有读到样本，不代表当天消耗或睡眠为 0。
  4. 保持手机解锁，运行一次，允许读取活动能量、睡眠及访问上传地址。然后回 Daybook「健康」刷新，核对日期和数值。

先跑通一次，再设置自动化。如果获取到的睡眠“值”与你的版本不同，请保留返回提示，调整字段后可重复补传。服务端和网页已经过模拟样本验证；上述动作仍需在你的 iPhone 上完成首次实测。

5 · 自动补传

在「自动化」中选择打开“健康”App 时 → 运行“Daybook 健康同步”，使用系统提供的立即运行选项。也可把快捷指令加到主屏幕，随手点一次。

每次查询最近 3 天，已同步样本会去重。若更久没有同步，可以临时把范围改为最近 7 天补传。长期锁屏时健康数据可能无法访问，定时触发不保证能读到数据。

日常只运行快捷指令，不需要打开 Daybook。网页、安卓 App 使用同一本 Book 即可看到数据，无需升级安卓安装包。

如何看这些数值

活动热量：只累计已记录的活动消耗，不包含静息消耗，也不估算没有佩戴时的消耗。

睡眠：按一次睡眠结束的日期归档，显示记录到的睡眠时长和可用分期；中途摘表可能导致记录不完整。

缺少数据的日期显示横线。已有真实 0 千卡样本才显示 0。原有体脂秤数据继续独立保存。
